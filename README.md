# TOEIC Speaking 学習管理ダッシュボード

「改訂版TOEIC(R)スピーキングテスト究極のゼミ」を軸にした、3トラック進捗の学習管理アプリ。
外部依存ゼロの単一静的サイト（ビルド不要・オフライン動作・進捗は端末の localStorage に保存）。

- **① ゼミ**（教科書：第1回〜第11回＋直前チェックリスト、全109項目・119ページ）を一周
- **② 模試**（模試1〜3）を3周、周回グリッド＋任意スコア入力（0〜200・10点刻み）
- **③ 演習**（Q1-2/Q3-4/Q5-7/Q8-10/Q11 のタイプ別、計57問）を2周
- 試験日・①ゼミ締切・②③締切・目標スコアは設定モーダルから変更可能（既定値あり）
- 締切から「今日やるべき量」と 前倒し/遅れ を自動計算、**目標スコアのライン**つきスコア推移

## 使い方

`index.html` をブラウザで開くだけ。ローカルサーバでも可。

```bash
python3 -m http.server 8976
# → http://127.0.0.1:8976
```

- ①ゼミ：セクションを開いて、読み終えた項目の行をタップで完了トグル。
- ②模試：グリッドのセルをタップで完了、右上「⋯」でスコア（0〜200・10点刻み）入力。
- ③演習：グリッドのセルをタップで完了トグル（スコア入力なし）。
- ヘッダ右上の歯車ボタンから、試験日・①ゼミ締切・②③締切・目標スコアを設定。
- フッタから進捗の **エクスポート/インポート（JSON）** とリセットが可能。

## 構成

Finder で迷わないよう、入口2つを日本語名で用意しています。

| ファイル | 役割 |
|---|---|
| `アプリを起動.command` | **アプリの入口（Mac）**。ダブルクリックでダッシュボードが開く（無料AIモード込み） |
| `はじめにお読みください.html` | **説明書の入口**。開くと `guide.html`（使い方ガイド）へ移動 |
| `index.html` | 学習ダッシュボード本体（プレーンな `<script>` で `assets/data.js` → `assets/app.js`） |
| `chat.html` | AI解説チャット本体（`assets/` の chat 系 CSS/JS を読み込み） |
| `guide.html` | 使い方ガイド本体（初心者向け・自己完結の1ページ読み物） |
| `assets/` | アプリの部品置き場（`styles.css` / `app.js` / `data.js` / `chat.css` / `chat-*.js`） |
| `local-bridge/` | 無料AIモード用のローカルサーバ（`claude` CLI 経由） |
| `tools/build-seminar-data.mjs` | `bookIndex.json` から①ゼミの `sections` 配列（セクション名とページ数のみ）を生成する一回きりのスクリプト |
| `DESIGN.md` | デザイン規約（配色・タイポ・余白・モーション） |

## ローカルサーバ / ポート

| サーバ | ポート | 用途 |
|---|---|---|
| 静的配信（`python3 -m http.server`） | `8976` | ダッシュボード本体のプレビュー |
| AI解説チャットのローカルブリッジ（`local-bridge/server.mjs`） | `8977` | 無料AIモードの `claude` CLI 呼び出し |

`local-bridge` / `chat.html` は TOEIC Speaking 版に合わせて調整済みです
（ブリッジは `127.0.0.1:8977` で待受、CORS許可オリジンは `127.0.0.1:8976`/`8977` と
公開URL、IndexedDB/localStorageのキー・エクスポート名は `toeicsw-*` 系、AI解説の
システムプロンプトも TOEIC Speaking 専属コーチ向けに書き換え済み）。

## データについて

進捗データは各ブラウザの localStorage に保存され、外部送信は一切ありません（ネットワーク通信ゼロ）。
別端末へ移す場合はフッタの JSON エクスポート/インポートを使用してください。
（AI解説チャットの利用時のみ、画像・質問が Anthropic またはローカル CLI に送られます。詳細は `guide.html` を参照。）

`assets/data.js` の①ゼミ教材データ（セクション名・ページ数）は、著作権保護のため
`textJa`/`textEn`/`prompt`/`modelAnswer` 等の本文フィールドを一切含みません
（目次レベルの情報のみを `tools/build-seminar-data.mjs` で抽出）。
